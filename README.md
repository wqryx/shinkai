# Shinkai 深海

**Live:** https://wqryx.github.io/shinkai/

A scroll-driven descent through the five zones of the ocean, from the sunlit surface to the floor of the Challenger Deep at 10,935 m. Inspired by [Kage](https://mengto.github.io/kage/).

- Live depth gauge with pressure, temperature, sunlight and reference points (Titanic, Everest, Shinkai 6500…)
- Three.js scene with custom shaders: marine snow, bioluminescence, jellies, a lanternfish school, an anglerfish that bites, a tripod fish, a hadal snailfish and the bathyscaphe Trieste
- Ambient sound synthesised in the browser with Web Audio
- English and Spanish
- Autopilot "Start the dive" mode

Single file, no build step: open `index.html` or serve the folder with any static host.
